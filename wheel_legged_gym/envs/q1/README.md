# q1：混合地形、平衡与转向训练

`q1` 是独立正式任务，继承 `q1_flat` 的六关节映射、URDF、初始姿态与基本动力学。
默认 **4096 个并行环境、30000 轮 PPO 更新**，每轮每环境 48 个策略步，策略 100 Hz、物理 200 Hz。
保留原任务作对照；本次未修改 Q1 的 URDF、质量惯量或碰撞体。

## 启动

在已安装 Isaac Gym Preview 4 和匹配 CUDA/PyTorch 的环境中，从项目根目录执行：

```bash
pip install -e .
swanlab login
python wheel_legged_gym/scripts/train.py --task=q1 --headless
```

无需再传环境数或轮数。q1 默认 `--q1_stage=turning`；`--q1_stage=low_speed` 保留原停车/前后直行采样，
`--q1_stage=balance` 只训练零指令平衡。q1_flat 默认仍为 low_speed，不能使用 turning。
配置在 `q1_config.py`，环境在 `q1.py`。已有 q1 的 31/155 维观测接口保持不变，可以继续训练；
**不能直接加载 q1_flat 的 27/135 维检查点**。

训练、键盘遥控和自动评估的 vx 上限统一为 **±0.8 m/s**。
`Q1Cfg.commands.max_forward_speed=0.8` 是训练阶段配置和遥控限幅共用的设置，
balance 仍保持零训练指令；low_speed 名称保留兼容，前后速度范围也已扩到 ±0.8 m/s。
非零训练幅值仍从 0.15 m/s 起采样，正负方向均衡，50% 取上限。
加速度仍为 0.4 m/s²，零到 ±0.8 约 2 s，完全反向约 4 s；W/S 每次加减 0.2，四次可到上限。
观测与网络维度不变，旧 q1 权重可续训以适应扩大后的速度范围及恢复的对称约束。

## 默认复杂地形

参考 `Dreamwaq-highplatform/legged_gym/envs/t0/t0/t0_config.py` 的有效地形和
`legged_gym/terrains/generators/rough.py` 的默认参数，复用 Isaac Gym 的同类生成器：

| 地形 | 比例 | Q1 参数 |
|---|---|---|
| 平地 | 10% | 保留停车、腿姿与双轮滚动训练 |
| 下坡、上坡 | 各 10% | 坡度 rise/run 为 0.05–0.35，原范围的一半；不是角度值 |
| 粗糙坡 | 15% | 坡度 0.05–0.25，起伏 ±2.5 cm，均为原范围的一半 |
| 下楼梯、上楼梯 | 各 20% | 单级高度 2.5–20 cm；上限单独设为 20 cm，非整段楼梯总高度 |
| 离散障碍 | 15% | 最大障碍高度范围 2.5–15 cm，为原范围的一半；保留原生成器的正负高度采样 |

保留 8×8 m 地块、20×20 地形网格、25 m 边界、0.1 m 水平/0.005 m 垂直采样。
踏面宽度参数仍为 0.25 m，和四轮足 T0 相同；Gym 按水平网格取整后实际为 0.20 m。
障碍尺寸仍为 1–2 m、数量 20；出生平台仍为 3 m。减半作用于坡度和高度范围，
不会缩小踏面或障碍间距。T0 中比例为零的空心楼梯、高平台继续不启用。
课程从第 0–2 行开始，按 0–1 插值到最后一行，最后一行上下楼梯的单级高度均达到 20 cm。
环境数和训练轮数仍是 **4096、30000**；`q1_flat` 继续是原平地任务。

平地每 4 s 重采样，25% 停车；复杂地形保持 20 s 的移动或转向指令，不主动采样停车，
给 0.15–0.8 m/s 的直行机器人留出离开出生平台的时间；保留 turning 阶段的原地/行驶转向。`balance` 阶段仍全程零速度。
正常完成回合、实际离开出生点至少 2 m、运动量与速度误差合格才升级；倒地或明显未跟随指令则降级。
纯停车、空转抖动或只待在出生平台不能升级。

复杂地形的高度奖励和倒地检查使用实际承重轮子的几何底部按垂直载荷加权作为支撑高度，
避免机身先越过台阶边缘、轮子仍在低处时，采样地面突升 20 cm 导致误判倒地。
离地时使用根坐标与轮子投影点中较低的采样地面；重置时按出生地块刷新参考。
机身碰撞和倾倒仍独立终止。轮子离地高度扣除当地地形高度，
滑移沿当地地面切向计算。楼梯陡面经过 mesh 转换的位置只能由高度图近似，
因此复杂地形上以实际接触力判定支撑，不用采样高度否决真实接触。
复杂地形关闭固定腿姿及抑制腿运动的代价，恢复左右腿软对称惩罚，允许单轮短时卸载；仍惩罚双轮同时失去支撑，
保留姿态、碰撞、关节限制、滑移和倒地约束，放宽高度奖励以允许悬架越障。
重置时立即刷新新地块高度，避免把上一地块的高度送入 critic。

## 训练逻辑检查与剩余限制

- 已修复跨步的 `time_outs` 和 episode 指标残留。每步生成独立 infos、发送当前 timeout 掩码，
  避免超时重置后下一步并未结束，却再次向 PPO 奖励补加价值。
- 已修复机身跨 20 cm 台阶边缘时的高度参考突变，新增无碰撞且水平的跨边缘回归测试，
  并保留真实低高度、机身碰撞和倾倒的失败检查。
- 默认 turning 的复杂地形指令仍为直行/原地转向/行驶转弯各约 1/3。
  旧 ±0.3 m/s 设置下，对 12000 次采样做理想跟踪、包含指令限速的 20 s 平面轨迹积分，约 60.4% 未离开 3 m 出生平台。
  该统计不是物理训练通过率，也不适用于本次 ±0.8 m/s 设置。原地转向回合仍可能不接触障碍；以越障为主时先用
  `--q1_stage=low_speed`，或后续提高复杂地形的直行比例，平地保留转向采样。
- 平地占 10%，只有平地采样 25% 停车，停车指令整体占用比例约 2.5%；复杂地形的出生平台也关闭腿姿代价。
  若目标仍包含高质量停车和站姿，应单独验收停车，后续考虑按当地地面平整程度启用姿态约束。
- 腿动作裁剪为 ±1、角度尺度 0.35 rad，大腿目标 0.25–0.95 rad、小腿目标 -1.55 至 -0.85 rad。
  根据当前两段 0.2 m 腿的解析 FK，机身水平时目标髋到轮心的垂直行程约 11.7 cm。
  这不证明 20 cm 台阶无法通过，但大台阶可能依赖机身姿态变化或跳跃，不能当作普通滚动越阶保证。
  Actor 没有前方高度输入，77 点高度图仅供 critic；当前属于靠接触和短历史反应的盲走策略。

上述检查不替代 Isaac Gym 接触验证；环境数量 4096、训练轮次 30000 和 20 cm 台阶上限保持不变。

网络维度保持 Actor 31、历史 155、特权观测 151。旧 `q1` 平地检查点维度兼容，
可用指定 `--load_run` 的续训命令适应新地形；旧奖励曲线不能直接与新混合地形比较。

续训同一个 q1 任务时可使用：

```bash
# RUN_NAME 替换成 logs/q1 下实际运行目录名。
python wheel_legged_gym/scripts/train.py --task=q1 --q1_stage=turning --resume --load_run=RUN_NAME --checkpoint=10000 --headless
```

`max_iterations` 表示本次额外训练轮数；默认续训再训练 30000 轮。
修正后的 runner 在每个检查点中保存已完成的累计轮数，恢复 PPO 与速度估计器优化器状态，文件编号对应累计更新数。
旧代码保存的中间检查点若把 iter 写成 0，该历史信息无法自动恢复；本次 q1 新训练使用正确编号。

## SwanLab 日志

q1 默认使用 `runner.logger="swanlab"`，项目为 `Q1`，在线模式与四轮足主训练的配置一致。
SwanLab 控制台会显示实验链接，实验名称沿用本地运行目录名，分组默认使用 run_name（通常为 turning）。
首次在训练环境安装更新后的项目依赖并运行 `swanlab login`；之后训练命令无需额外日志参数。
SDK 依赖版本沿用四轮足仓库：Python 3.8 使用 swanlab 0.7.20，Python 3.9+ 使用 0.10.2–0.10.x。

记录全部 `Episode/*`、`Loss/*`、`Policy/*`、`Perf/*`、`Train/*` 标量，包括各项奖励、
PPO/encoder 损失、学习率、KL、动作噪声、平均回报和回合长度，以及 q1_yaw_mae、
q1_speed_mae、q1_both_wheel_duty、q1_slip_speed、q1_wheel_saturation、q1_parking_drift 等质量指标。
回合指标在机器人完成回合后出现，训练刚开始时可能尚无 Episode 曲线。

环境与训练的完整解析配置会写入实验配置。每次新训练或续训创建独立 SwanLab 实验，
续训时曲线横轴继续使用检查点累计轮数；配置中记录来源检查点、来源 SwanLab 实验 ID 和起始轮数。
新检查点包含 swanlab_run_id，仍兼容不含该字段的旧 TensorBoard 检查点。
播放只加载模型，不创建或上传 SwanLab 实验；模型文件仍只保存在本地。

本地路径保留：模型和 resolved_config.json 在 `logs/q1/<运行目录>/`，
SwanLab 数据在该目录的 `swanlog/`，TensorBoard 事件文件也在该运行目录内。
正常结束或训练异常退出时关闭日志，刷新本地备份并结束 SwanLab 实验。

```bash
# 不联网、不要求账号登录；日志写入本地 swanlog。
python wheel_legged_gym/scripts/train.py --task=q1 --headless --swanlab_mode=offline
# 自定义 SwanLab 项目
python wheel_legged_gym/scripts/train.py --task=q1 --headless --swanlab_project=my-q1
# 只使用原来的本地 TensorBoard
python wheel_legged_gym/scripts/train.py --task=q1 --headless --logger=tensorboard
tensorboard --logdir=logs/q1
```

`SWANLAB_MODE` 环境变量优先于模式参数；团队空间可通过 `SWANLAB_WORKSPACE` 或配置中的 swanlab_workspace 设置。
原 wheel_legged、VMC 和 q1_flat 任务默认仍使用原日志方式，可显式传 `--logger=swanlab` 切换。

## 训练视频和 GIF 上传

默认启用 `Q1CfgPPO.runner.periodic_video`，沿用四轮足的独立检查点评估进程：
每完成 1500 轮先保存模型，再运行一个单环境 headless 子进程录制 12 s，主训练等待这段录制结束后继续。
录制期间不推进或修改主训练环境，不启用主训练进程的相机；主训练仍为 4096 个环境、30000 轮。
录制轮次与 save_interval 独立，续训按累计轮数触发；30000 轮的片段只录制一次。

MP4 为 1280×720、25 fps；SwanLab GIF 预览为最高宽 640 像素、10 fps，
用 `swanlab.Video` 发布到当前实验的 `video` 媒体卡片，与相应模型的训练轮次关联。
本地保留 `videos/training/iteration_001500.mp4`、`iteration_001500.swanlab.gif`、
包含检查点/指令/帧数的同名 JSON 和子进程 `.render.log`，都位于当前运行目录下。
TensorBoard 模式仍录制本地 MP4；SwanLab offline 模式只记录本地媒体，不进行云端上传。

评估读取当前运行的 `resolved_config.json`，直接加载该轮策略，不启动新的 SwanLab 实验。
默认只生成单块平地，按 3 s 停车、3 s 前进 0.8 m/s、3 s 原地左转 0.4 rad/s、
3 s 后退 -0.8 m/s 并右转 -0.3 rad/s 的顺序展示。balance 阶段全程零指令，low_speed 阶段屏蔽转向；
前后与转向仍使用训练时的指令变化限制。它是固定指令评估视频，不代表复杂地形训练通过率。

可在 periodic_video 配置中改 `terrain_type="stairs_up"`、`terrain_difficulty=0.25` 来录制楼梯，
或选择其他 Q1 地形类型；难度为 0–1，1 对应配置上限。视频地形设置不修改训练课程。
通过 `enabled=False` 关闭录制；interval、duration_s、fps、width、height、相机偏移和 command_schedule 也可配置。
给出 command_schedule 时，片长取各段 duration 的总和；Q1 每段格式为 `(秒数, vx, yaw_rate)`，没有侧移项。

更新依赖时执行 `pip install -e .`，新增 imageio-ffmpeg 可在系统无 ffmpeg 时提供编码器。
headless 录制仍需可用的 GPU 图形/Vulkan 支持；只有录制子进程开启相机。
子进程失败或超过默认 180 s 超时会打印日志位置并继续训练；转换/上传失败会保留本地文件，
等待 60 s 后在后续轮次重试。成功上传的片段不重复发送。

## 改进内容

| 项目 | q1 的做法 |
|---|---|
| 指令采样 | 平地每 4 s，turning 阶段停车、直行、原地转向、行驶转弯各约 25%；复杂地形每 20 s，三类非停车指令均分；前后幅值 0.15–0.8 m/s，转向幅值 0.2–0.6 rad/s，正负方向均衡，每类非零幅值 50% 取上限 |
| 加减速 | 前后指令限制 0.4 m/s²，转向指令限制 0.8 rad/s²；训练与播放共用，含反向和停车 |
| 转向奖励 | 跟踪实际物理步使用的 yaw 指令，权重 1.0；原地转向另加 0.5 的角速度跟踪奖励，避免只学会直行 |
| 速度精度 | 行驶指数奖励 sigma=0.0064，稳定停车 sigma=0.0025，并增加带 0.02 m/s 容差的速度误差代价 |
| 大速度误差 | 保留 0.15 m/s 的绝对误差尺度，将代价裁剪范围扩大到覆盖全正反向速度差；避免超过约 0.32 m/s 后误差代价全部饱和 |
| 实际腿姿态 | 平地对四个腿关节的实际误差设置 0.08 rad 容差，结合平均和最差关节惩罚；复杂地形关闭该项；排除轮累计转角 |
| 左右姿态（全地形启用） | 配置权重 leg_symmetry=-0.10，允许 0.08 rad 误差；rough_leg_symmetry_weight=1.0 恢复复杂地形约束，转向时渐降至原权重的 50%，并保留加速/倾斜恢复时的放宽 |
| 平衡恢复 | 前后/转向加减速和机身倾斜时降低姿态及腿运动约束强度，保留调重心空间 |
| 高度 | 目标为相对当地地面 0.397 m，初始高度为出生地块高度加 0.402 m；复杂地形放宽高度奖励 |
| 轮控制 | 各轮目标速度 = (vx - yaw_rate × wheel_y)/r + 策略残差；轮中心 Y 为 +0.14927/-0.14973 m；正 yaw 左轮减速、右轮加速。轮速度反馈增益 0.20，目标速度与最终力矩受 URDF 限制 |
| 接地 | 每个物理子步检查真实接触力和相对地面的离地高度，累计接触占空比；平地约束双轮贴地，复杂地形允许单轮短时卸载 |
| 滑移 | 使用轮 link 世界线速度、完整世界角速度及轮碰撞体的接触点计算切向残余速度；包含机身和腿的转动，不把轮关节相对速度直接当世界轮速 |
| 停车 | 前后和转向目标/实际指令均接近零后才计时，等待 0.5 s 记录停车点，再用 0.5 s 渐入位置约束；原地转向不触发停车或锁轮代价 |
| 直线 | 只有目标和限速后的 yaw 指令均低于 0.05 rad/s 才启用固定直线参考；转弯及 yaw 减速过渡期关闭，恢复直行后按当前位置和航向重新建线 |
| 倒地 | 失败与正常 timeout 分开，失败恰逢时限也算失败；倒地惩罚 -2 为一次事件，不再缩小成每秒项 |

所有增益和权重是有物理约束的初始训练设置，尚需实际训练确认性能。
没有加入强制锁轮 PI，也没有把四轮腿的 command 数组或镜像符号直接复制过来。
Q1 的前三个命令依然为 `[vx, yaw_rate, height]`。

参考原双轮腿 `envs/base/legged_robot.py` 的 yaw 指令采样/指数跟踪，以及四轮足
`Dreamwaq-highplatform/legged_gym/envs/t1/t0_highspeed/t0_highspeed.py` 的任务分组、原地转向奖励、
直线 mask 与转向时适度放宽运动约束。Q1 不采样侧移，不复制四轮足 `[vx, vy, yaw]` 的索引。
双轮差速前馈使用 Q1 本身的轮中心位置，不使用四轮腿转向时的轮速符号。

## 观测与部署接口

- Actor：31 维。原有 27 维后追加停车点相对位移 XY、直线横向误差、航向误差。
- 追加通道分别按 0.15 m、0.20 m、0.20 rad 归一化并限幅；无对应任务时置零。
- 历史：5 帧，共 155 维。速度估计 latent：3 维。
- 特权观测：151 维；保留原布局、增加上述 4 维和双轮离地高度/接触力 4 维。critic 加 latent 后共 154 维。
- 停车和路径参考是局部参考，不使用世界绝对坐标作为 Actor 特征。仿真由 root 状态计算；部署必须提供本地里程计/航向估计并复现参考点建立时机，不能把新增通道长期填零。
- 轮轴均为 +Y，策略关节顺序与 q1_flat 一致。动作残差顺序为左大腿、左小腿、左轮、右大腿、右小腿、右轮。
- 新轮差速速度前馈、前后/转向指令限速、转弯期间参考清零与恢复直行重建参考的规则都必须在部署中复现。

# 指定某次运行

默认播放为键盘控制，点击仿真窗口取得焦点后操作，直到 Esc 或关闭窗口退出。
键位沿用四轮足主播放程序：

| 按键 | 功能 |
|---|---|
| W / S | 当前机器人目标前后速度每次加 / 减 0.2 m/s；松开保持，限制在 ±0.8 m/s |
| A / D | 当前机器人目标转向角速度每次加 / 减 0.2 rad/s；正值左转、负值右转，松开保持，限制在 ±0.6 rad/s |
| X | 当前机器人目标前后速度和转向角速度归零；两者按各自加减速限制平滑停车 |
| 空格 | 暂停 / 继续；暂停期间处理键盘和相机，不推进物理 |
| R | 重置当前机器人并将其目标速度归零 |
| F | 自由相机 / 跟随当前机器人 |
| 0–8 | 选择对应机器人，越界选择会忽略 |
| [ / ] | 上一个 / 下一个机器人，循环选择 |
| Esc / V | 退出 / 切换 viewer 渲染同步 |

速度只修改当前选择的机器人，其他机器人保持各自指令。自动重置后仍保持键盘设定，R 则主动清零。
默认跟随机器人 0。J/L 不绑定功能，Q1 没有侧移指令通道。
键盘通过 `[vx, yaw_rate, height]` 的第 2 项传递转向，保持第 3 项高度不变。
turning 阶段训练左右原地转向和行驶转弯。旧 low_speed 权重需要继续训练后再评估转向效果。
空格保持四轮足主播放程序的“暂停”含义，停车使用 X。
键盘模式可用 `--play_duration=120` 限制仿真时长，暂停不计入时长。

自动评估显式使用：

```bash
python wheel_legged_gym/scripts/play.py --task=q1 --num_envs=1 --play_mode=auto
```

`--headless` 自动采用 auto 模式。auto 在 plane 上默认 72 s、每 4 s 切换；复杂地形每 20 s 切换并默认播放完整序列（turning 为 360 s、low_speed 为 180 s），显式 `--play_duration` 仍优先；默认 turning 测试直行、
左右原地转向（±0.3/±0.6 rad/s）、前进/后退转弯及停车。完整 `[vx, yaw]` 顺序见摘要 JSON 的 schedule_vx_yaw。
`--q1_stage=low_speed` 只测试原来的前后直行，`--q1_stage=balance` 全程零指令。
实际命令仍有前后与转向加减速限制。
自动评估直行和行驶转弯覆盖 ±0.4 m/s 中速及 ±0.8 m/s 端点。
单独看最高楼梯时，可在 `Q1Cfg.terrain` 中设置以下参数后播放：

```python
selected = True
curriculum = False
selected_type = "stairs_up"  # 或 stairs_down
selected_difficulty = 1.0
```

播放后恢复 `selected=False, curriculum=True`，再进行默认混合地形训练。
CSV 和摘要 JSON 位于 `logs/q1/exported/evaluations/`，JIT 位于 `logs/q1/exported/policies/`。
评估目录放在 exported 下，避免自动加载把评估目录误判为最新训练运行。

CSV 每个策略步记录环境 0：目标/实际施加指令、机身速度、roll/pitch、高度、腿实际角度和 PD 目标、
轮速/轮目标/力矩、双轮接触力/占空比/离地高度、滑移、力矩饱和、停车偏移、路径偏移和航向误差。
末尾追加 target_yaw_rate、applied_yaw_command、next_yaw_command，保留原字段顺序。
诊断在重置前采样，倒地帧不会被重置后的正常状态掩盖。
JSON 中 mean_absolute_signals 是各信号绝对值的整体均值，停车和运动阶段需根据 CSV 分别统计。

SwanLab（及本地 TensorBoard 备份）的 Episode/q1_* 指标记录每个完成回合的速度 MAE、最大腿关节误差的时间均值、
双轮接触占空比、滑移、力矩饱和率、停车偏移和 q1_yaw_mae（rad/s）。这些整体回合指标混合了多类指令，
应结合 CSV 按停车、直行、原地转向、行驶转弯分别统计，不用停车零值稀释转向误差。

建议验收：停车段持续速度和累计位移、匀速段速度 MAE、左右轮支撑、腿姿态最大误差、滑移与力矩饱和，
并分别检查加速、减速、停车恢复。小幅纠偏是双轮动态平衡的一部分，不能以轮子完全不动作为唯一标准。
转向验收另看左右方向是否正确、转向段 yaw 误差与机身位移、前进/后退四种转弯组合、停止转向后的恢复，
以及差速过程中是否抬轮、倒地或持续力矩饱和。

## 固定地形键盘播放 keyboard_play

参考四轮腿 `Dreamwaq-highplatform` 的播放流程和相机控制新增独立入口：

```bash
# 默认 q1、6 个环境；读取最新训练目录的第 30000 轮模型
python wheel_legged_gym/scripts/keyboard_play.py --task=q1 --checkpoint=30000
# 明确指定训练目录，避免加载到别的实验
python wheel_legged_gym/scripts/keyboard_play.py --task=q1 --load_run=你的训练目录名 --checkpoint=30000
# 只看上楼，难度 1 对应单级 20 cm（建议先从 0.5 开始）
python wheel_legged_gym/scripts/keyboard_play.py --terrain=stairs_down --difficulty=1 --num_envs=1 --checkpoint=30000
```

`--terrain` 支持 mixed、flat、slope_up、slope_down、rough_slope、stairs_up、stairs_down、discrete。
默认 mixed 按机器人编号依次分配 stairs_down、stairs_up、slope_up、slope_down、rough_slope、flat；
第 7 个加入 discrete，之后循环。即使只播放 1 个环境也保证有楼梯。
地形使用训练时相同的 Gym primitives、8 m 地块、3 m 中央平台、分辨率与台阶宽度，固定一个难度，
不沿用训练日志里的平均课程等级。默认 difficulty=0.5，台阶名义高度 11.25 cm，
受 5 mm 栅格量化约为 11 cm；difficulty=1 是 20 cm。

**名称和驾驶方向：**原楼梯是金字塔地形，机器人出生在中央。stairs_down 中央低，向外开是上楼；
stairs_up 中央高，向外开是下楼。坡地也有同样的中心高低关系。默认首先跟随 0 号上楼机器人。
刚开始静止时看到平台是正常的，按 W 加速，行驶约 1.5 m 到达平台边缘；R 可重置选中的机器人。

W/S 每次增减 0.2 m/s、范围 ±0.8；A/D 每次增减 0.2 rad/s、范围 ±0.6；松键后保持目标。
X 将当前机器人速度/转向目标归零（仍按加减速限制过渡），Space 暂停/继续，0–8 或 [ / ] 选择机器人，
F 自由/跟随相机，跟随模式保留鼠标调整的视角和距离，Esc 退出，V 切换显示同步。J/L 不启用。
指令只作用于当前机器人，其余机器人保留各自目标，切换机器人不会自动停车。
终端打印当前机器人、地形、目标和实测速度；CSV 仍记录环境 0，摘要 JSON 追加地形分配和难度。

此入口关闭观测噪声、域随机化和随机推力，加载模型后使用确定性策略均值，并打印检查点 std。
不会启动训练或 SwanLab 新实验。训练配置和原 `play.py` 的地形默认保持原样。
动作噪声很大或轮力矩长期饱和仍需进一步排查，不能用总奖励或平均地形等级代替上楼验收。
